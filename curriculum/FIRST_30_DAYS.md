# Your first 30 days

Use five 3-hour study sessions per week, leaving two days for rest or catch-up. The days below are study days, not a demand to work every calendar day. This is the first pass through foundations; Stage 01 continues with deeper practice after the month ends.

For each session, keep the last 15 minutes for a short explanation from memory and a progress entry. Avoid opening solutions until you have a written attempt. Ask for a hint if stuck after 20–30 minutes.

| Week / session | Learn and practice | Deliverable |
|---|---|---|
| 1 / 1 | Terminal, folders, Python, environment, notebook kernel | hello.py and 00a example, interpreter path recorded |
| 1 / 2 | Run cells, restart kernel, variables, print, assertions | Complete 00a; explain a deliberate NameError |
| 1 / 3 | Git status/diff/add/commit, .gitignore | Two small commits and a written explanation of each diff |
| 1 / 4 | Branches, merge, a small deliberate conflict, GitHub | Branch merged and a private/public repository chosen deliberately |
| 1 / 5 | Reproducibility manifest and AI vocabulary | Stage 00 project and gate; schedule reviews |
| 2 / 1 | Numbers, strings, booleans, operators | 01a worked example and hand-traced expressions |
| 2 / 2 | Conditions, function arguments, return, errors | 01a exercises and boundary tests |
| 2 / 3 | Loops and lists | Calculator loop and temperature converter |
| 2 / 4 | Dictionaries, sets, tuples, comprehensions | 01b word-count and deduplication exercises |
| 2 / 5 | Inventory, contact book, testing examples | Small CLI demonstration without reading a solution |
| 3 / 1 | Text files, paths, context managers | Read/write a UTF-8 notes file safely |
| 3 / 2 | CSV/JSON and Decimal | 01c parser and exact-money checks |
| 3 / 3 | Dates, grouping, validation | Expense totals by category and month |
| 3 / 4 | Modules, exception boundaries, CLI arguments | Analyzer split into modules; malformed row has a line number |
| 3 / 5 | Restart/re-run and peer explanation | First project report with expected fixture total 100.00 |
| 4 / 1 | pytest, normal/boundary/error cases | Tests for empty CSV, invalid date, NaN, and negative amounts |
| 4 / 2 | Tracebacks, breakpoints, logging, mocks | Bug diary with reproduction, hypothesis, fix, regression test |
| 4 / 3 | Classes, constructors, methods, composition | 01d inventory; prove separate instances do not share state |
| 4 / 4 | Search, sort, recursion, complexity | Binary search, a recursive base case, and timing notes |
| 4 / 5 | Independent mini-assessment | New inventory summarizer from an empty file; score with rubric |

During the remaining calendar days, rest, catch up, or repeat the weakest task from memory. If a week is too fast, repeat it; the plan is a budget, not a deadline.

At the month-end review, explain why functions return values, when dictionaries help, how files are parsed, where validation belongs, what an exception means, how tests detect regressions, and why copying a passing solution is not evidence of understanding. Stage 01 has additional time for independent practice; do not jump to agents because one CLI works.
