## Before the exercises: Measuring a model server honestly

Read this in small pieces. Explain each new term in your own words, trace the example on paper, and change one input before continuing. If the arithmetic is unfamiliar, use [the math bridge](../MATH_START_HERE.md).

### Concepts in plain language

A model server accepts a request and returns generated output. A client must validate response shape, bound input/output size, and set a timeout. HTTP compatibility describes an interface, not identical behavior or performance across backends.

Cold measurement includes a specified unloaded/startup condition; warm measurement uses a resident initialized model. Define exactly where the timer begins. Time to first token needs streaming instrumentation; a non-streaming end-to-end duration cannot reveal it.

Percentiles describe a distribution of observations: p50 is a median-like middle value and p95 is a high-tail value under a stated convention. Include failures, output lengths, model identity, and concurrency so comparisons are interpretable.

### Worked example: follow the values

If two concurrent requests each take 2 seconds and produce 10 tokens, total wall time can be about 2 seconds. Batch throughput is 20/2=10 tokens/sec, not 20 divided by the summed 4 seconds. Keep request latency and batch throughput as separate measurements.
