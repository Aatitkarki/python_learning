### Concepts in plain language

A transformer block combines attention, a feed-forward network, normalization, and residual connections. A residual adds the original representation back to a transformed version, helping information and gradients flow. Position information distinguishes the same token appearing at different locations.

A causal language model predicts the next token. If a sequence is `[A,B,C,D]`, one training input is `[A,B,C]` and the target is `[B,C,D]`. Splitting the corpus before making overlapping windows reduces train/test overlap.

During generation, a KV cache stores earlier keys and values for each attention layer. The new token contributes a new query/key/value; its query attends to past cached keys and the present key. Cache length determines the next position index. Each layer needs its own cache.

### Common mistakes to check

Off-by-one targets and reset position indices can produce plausible-looking code with incorrect semantics. Separate caches by request/user.
