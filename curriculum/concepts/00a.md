## Before the exercises: Programs, files, and the notebook kernel

Read this in small pieces. Explain each new term in your own words, trace the example on paper, and change one input before continuing. If the arithmetic is unfamiliar, use [the math bridge](../MATH_START_HERE.md).

### Concepts in plain language

A source file stores instructions as text. Python is the interpreter that executes those instructions. A terminal is a place to type commands; it is not itself the Python language. A notebook combines explanations and executable code cells. Its kernel is the running Python process, which remembers names between cells.

`count = 3` binds a name to a value. `print(count)` displays the value. `assert count == 3` checks a claim and raises an error if the claim is false. A traceback shows the calls leading to an error; start with its final line, then locate the line in your code.

A virtual environment is a separate collection of Python packages. The terminal and notebook should use the same environment. `sys.executable` identifies the interpreter actually running. Git records snapshots of chosen source files; saving a notebook and committing it are separate actions.

### Worked example: follow the values

Run `count = 3` in one cell and `print(count + 2)` in another: the output is 5. Restart the kernel and run only the second cell: `NameError` is expected because `count` no longer exists. Run both cells in order to restore a reproducible result. Nothing is wrong with restarting; it reveals missing setup.
