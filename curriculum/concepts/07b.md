## Before the exercises: Grounding and access-controlled evidence

### Concepts in plain language

A retrieved passage is a candidate, not proof of a claim. Grounding means the answer's claims follow from accessible evidence. A citation needs a source identity and a location that supports the particular statement. If evidence is missing, abstain or return unknown.

Parsing converts file formats to text. A scanned PDF may contain only images and require OCR. Tables can lose rows, columns, signs, and units when flattened. Inspect extracted numbers against original pages before indexing them.

Vector search compares stored embeddings with a query embedding. Both must use compatible model versions. PostgreSQL with pgvector stores and searches vectors, but tenant filtering and source permissions remain application responsibilities.

### Worked example: follow the values

A question asks revenue growth between two years. A chunk containing only the latest revenue cannot support growth by itself. Retrieve both comparable annual figures, calculate `(new-old)/old`, and cite both sources. A source that says 'ignore restrictions' remains untrusted data and cannot authorize another tenant's records.
