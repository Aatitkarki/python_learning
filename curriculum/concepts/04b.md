### Concepts in plain language

A confusion matrix counts actual versus predicted classes. Precision asks what fraction of predicted positives were correct. Recall asks what fraction of actual positives were found. F1 combines precision and recall through their harmonic mean. Macro-F1 gives each class equal weight; accuracy can conceal failure on a rare class.

Clustering groups observations without using target labels to fit. KMeans uses distances to centers; DBSCAN groups connected dense regions and can mark points as noise. Feature scaling changes distance. PCA finds directions of large variance for a lower-dimensional representation; large variance is not the same as predictive usefulness.

### Worked example: follow the values

If a detector flags 10 cases, 6 truly positive, while there were 8 actual positives, precision=6/10=.6 and recall=6/8=.75. F1 is `2*.6*.75/(.6+.75)`, about .667. On curved two-moon data, center-based partitions may split the wrong shapes even when they work on round blobs.
