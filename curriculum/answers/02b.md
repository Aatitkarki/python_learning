## 02b-E1: Numerical derivative

**Question:** Approximate f prime at x using a central difference with h > 0.

**Answer:**

```python
def derivative(f, x, h=1e-5):
    if h <= 0: raise ValueError("Positive step required")
    return (f(x+h)-f(x-h))/(2*h)
```

**Checks:**

```python
assert abs(derivative(lambda x: x*x, 3)-6) < 1e-6
expect_error(ValueError, lambda: derivative(lambda x: x, 0, 0))
```

**Why it works:** Central differences balance first-order truncation errors.

## 02b-E2: Linear gradient

**Question:** Return the MSE gradient for scalar w on equally sized nonempty xs, ys.

**Answer:**

```python
def mse_gradient(w, xs, ys):
    if not xs or len(xs) != len(ys): raise ValueError("Invalid data")
    return sum(2*x*(w*x-y) for x, y in zip(xs, ys))/len(xs)
```

**Checks:**

```python
xs, ys = [1, 2, 3], [2, 4, 6]
f = lambda w: sum((w*x-y)**2 for x,y in zip(xs,ys))/len(xs)
assert abs(mse_gradient(1, xs, ys)-derivative(f, 1)) < 1e-6
```

**Why it works:** Gradient checks detect signs, missing factors, and incorrect reductions.

## 02b-E3: Fit one weight

**Question:** Start at w=0, apply steps gradient updates, and return w. Defaults should fit y=2x.

**Answer:**

```python
def fit_weight(xs, ys, lr=0.05, steps=100):
    w = 0.0
    for _ in range(steps):
        w -= lr * mse_gradient(w, xs, ys)
    return w
```

**Checks:**

```python
assert abs(fit_weight([1, 2, 3], [2, 4, 6])-2) < 1e-6
```

**Why it works:** This is optimization of a known objective, not a general guarantee that learning works.

## 02b-T: Independent assignment

**Question:** Add an intercept, L2 regularization, and loss history. Compare rates 0.001, 0.05, and 1.0. Explain divergence from the update equation; save a loss plot.

**Test your own work:** [Interface, starter, and acceptance tests](../assignments/02b.md)

**Worked answer:** The regularized objective is mean((wx+b-y)^2)+lambda*w^2. Gradients are dw=2 mean(x*(wx+b-y))+2*lambda*w and db=2 mean(wx+b-y). gradient_check independently verifies both by central differences. The experiment compares rates .001, .05, and 1.0 with an intercept and L2=.1, saves loss histories as optimization.png, and reports fitted values. Regularization shrinks the slope, so demanding exactly w=2 would be a wrong check for the penalized problem. In a quadratic, stable updates require the step size to respect curvature; the large rate grows the error while the small rate learns slowly. Inspect the generated values rather than assuming every loss must decrease.
