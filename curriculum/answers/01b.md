## 01b-E1: Word frequencies

**Question:** Count lowercase words matching [a-z]+; return a dictionary. Empty text returns {}.

**Answer:**

```python
def word_counts(text):
    import re
    counts = {}
    for word in re.findall(r"[a-z]+", text.lower()):
        counts[word] = counts.get(word, 0) + 1
    return counts
```

**Checks:**

```python
assert word_counts("AI, ai! Data.") == {"ai": 2, "data": 1}
assert word_counts("") == {}
```

**Why it works:** This tokenizer is deliberately ASCII-only; multilingual text needs a different policy.

## 01b-E2: Stable deduplication

**Question:** Return the first occurrence of each hashable item, preserving input order.

**Answer:**

```python
def unique(items):
    seen, result = set(), []
    for item in items:
        if item not in seen:
            seen.add(item)
            result.append(item)
    return result
```

**Checks:**

```python
assert unique([3, 1, 3, 2, 1]) == [3, 1, 2]
assert unique([]) == []
```

**Why it works:** Expected O(n) time uses O(n) extra memory; a nested membership scan can be quadratic.

## 01b-E3: Inventory update

**Question:** Return a new dictionary with deltas applied. Reject a resulting negative count. Do not change the original.

**Answer:**

```python
def update_stock(stock, deltas):
    result = dict(stock)
    for item, delta in deltas.items():
        result[item] = result.get(item, 0) + delta
        if result[item] < 0: raise ValueError("Insufficient stock")
    return result
```

**Checks:**

```python
original = {"pen": 3}
assert update_stock(original, {"pen": -2, "book": 1}) == {"pen": 1, "book": 1}
assert original == {"pen": 3}
expect_error(ValueError, lambda: update_stock(original, {"pen": -4}))
```

**Why it works:** Returning a new result avoids partial mutations when validation fails.
