## 06a-E1: Character tokenizer

**Question:** Build sorted unique-character vocabulary. Return ids, encode mapping, and decoded text for the given nonempty string.

**Answer:**

```python
def tokenize(text):
    vocabulary = sorted(set(text))
    encode = {char: i for i, char in enumerate(vocabulary)}
    ids = [encode[char] for char in text]
    return ids, encode, "".join(vocabulary[i] for i in ids)
```

**Checks:**

```python
ids, vocab, decoded = tokenize("banana")
assert decoded == "banana" and len(vocab) == 3
```

**Why it works:** Real tokenizers also need handling for unknown text, normalization, and special tokens.

## 06a-E2: Causal attention

**Question:** Return output and attention weights for equal-length 2D Q,K,V. Mask all future positions before stable row softmax.

**Answer:**

```python
def attention(q, k, v):
    scores = q@k.T/np.sqrt(q.shape[-1])
    scores = np.where(np.triu(np.ones(scores.shape), 1).astype(bool), -np.inf, scores)
    weights = np.exp(scores-scores.max(axis=-1, keepdims=True))
    weights /= weights.sum(axis=-1, keepdims=True)
    return weights@v, weights
```

**Checks:**

```python
out, weights = attention(np.eye(3), np.eye(3), np.eye(3))
assert np.allclose(weights.sum(axis=1), 1)
assert np.allclose(np.triu(weights, 1), 0)
assert np.allclose(out[0], [1, 0, 0])
```

**Why it works:** A causal mask is a training-data boundary: future tokens would leak the answer.

## 06a-E3: Temperature distribution

**Question:** Return stable softmax(logits/temperature). Reject nonpositive temperature.

**Answer:**

```python
def distribution(logits, temperature=1.):
    if temperature <= 0: raise ValueError("Temperature must be positive")
    values = np.asarray(logits)/temperature
    p = np.exp(values-values.max())
    return p/p.sum()
```

**Checks:**

```python
assert distribution([0, 1], .1)[1] > distribution([0, 1], 2)[1]
expect_error(ValueError, lambda: distribution([1, 2], 0))
```

**Why it works:** Lower temperature sharpens a distribution; it does not guarantee factual correctness.
