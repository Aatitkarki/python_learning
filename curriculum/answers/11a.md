## 11a-E1: Mergeable average

**Question:** Return (sum,count) for each partition, combine, and return the global mean; reject zero total count.

**Answer:**

```python
def distributed_mean(partitions):
    total, count = 0, 0
    for partition in partitions:
        total += sum(partition)
        count += len(partition)
    if count == 0: raise ValueError("No observations")
    return total/count
```

**Checks:**

```python
assert abs(distributed_mean([[10, 20], [100]])-130/3) < 1e-12
assert distributed_mean([[], [3]]) == 3
```

**Why it works:** Many distributed bugs are caused by combining already-normalized results.

## 11a-E2: Grouped partial sums

**Question:** Merge a list of key→sum dictionaries into a new dictionary.

**Answer:**

```python
def merge_groups(partials):
    result = {}
    for partial in partials:
        for key, value in partial.items(): result[key] = result.get(key, 0)+value
    return result
```

**Checks:**

```python
assert merge_groups([{"a": 2}, {"a": 3, "b": 4}]) == {"a": 5, "b": 4}
```

**Why it works:** Floating-point reduction order can change low-order bits; compare with tolerances when appropriate.

## 11a-E3: Skew ratio

**Question:** Return largest nonnegative partition size divided by mean size; reject empty or all-zero input.

**Answer:**

```python
def skew_ratio(sizes):
    if not sizes or min(sizes) < 0 or sum(sizes) == 0: raise ValueError("Invalid sizes")
    return max(sizes)/(sum(sizes)/len(sizes))
```

**Checks:**

```python
assert skew_ratio([10, 10, 10]) == 1
assert skew_ratio([0, 0, 30]) == 3
```

**Why it works:** A single summary flags imbalance but does not explain its cause.

**Worked answer:** streaming_totals processes bounded index batches and maintains only 50 group accumulators. At one million rows, the exact total is 4,999,500,000 cents. It does not allocate a million-record list. The Spark comparison collects only the 50 aggregated result rows and checks each against this independent reference. Global means require sums/counts, not an average of unequal partition means. A shuffle redistributes keys; a broadcast join replicates a genuinely small dimension.
