## 10a-E1: SLO calculation

**Question:** Return fraction of events with ok=True and latency_ms<=target. Empty input raises ValueError.

**Answer:**

```python
def slo_fraction(events, target=500):
    if not events: raise ValueError("No observations")
    return sum(e["ok"] and e["latency_ms"] <= target for e in events)/len(events)
```

**Checks:**

```python
assert slo_fraction([{"ok": True, "latency_ms": 100}, {"ok": False, "latency_ms": 10}]) == .5
```

**Why it works:** A latency-only dashboard can look healthy while every request fails.

## 10a-E2: Log allowlist

**Question:** Keep request_id,status,latency_ms only; omit every other key.

**Answer:**

```python
def safe_log(event):
    return {k: event[k] for k in ("request_id", "status", "latency_ms") if k in event}
```

**Checks:**

```python
assert safe_log({"request_id": "x", "token": "secret", "prompt": "private"}) == {"request_id": "x"}
```

**Why it works:** Nested and newly added fields make denylist redaction fragile.

## 10a-E3: Idempotency conflict

**Question:** Given a mutable cache and key,payload,result, save (payload,result) on first call, return existing result for same payload, reject changed payload.

**Answer:**

```python
def remember(cache, key, payload, result):
    if key in cache:
        previous_payload, previous_result = cache[key]
        if previous_payload != payload: raise ValueError("Idempotency conflict")
        return previous_result
    cache[key] = (payload, result)
    return result
```

**Checks:**

```python
cache = {}
assert remember(cache, "k", {"x": 1}, 3) == 3
assert remember(cache, "k", {"x": 1}, 8) == 3
expect_error(ValueError, lambda: remember(cache, "k", {"x": 2}, 4))
```

**Why it works:** This in-memory teaching version is not atomic across processes; use a durable transactional store in production.
