## 02c-E1: Sample variance

**Question:** Compute unbiased sample variance for n >= 2; reject smaller samples.

**Answer:**

```python
def variance(xs):
    if len(xs) < 2: raise ValueError("Need two observations")
    mean = sum(xs)/len(xs)
    return sum((x-mean)**2 for x in xs)/(len(xs)-1)
```

**Checks:**

```python
assert variance([1, 2, 3]) == 1
expect_error(ValueError, lambda: variance([1]))
```

**Why it works:** The n-1 adjustment compensates for estimating the mean from the same sample.

## 02c-E2: Bayesian alert

**Question:** Return P(event|positive) from prevalence, sensitivity, and false_positive_rate in [0,1]. Reject an impossible positive event.

**Answer:**

```python
def posterior(prevalence, sensitivity, false_positive_rate):
    if any(not 0 <= p <= 1 for p in (prevalence, sensitivity, false_positive_rate)):
        raise ValueError("Invalid probability")
    true = prevalence*sensitivity
    positive = true + (1-prevalence)*false_positive_rate
    if positive == 0: raise ValueError("Impossible conditioning event")
    return true/positive
```

**Checks:**

```python
assert abs(posterior(.01, .9, .1)-(.009/.108)) < 1e-12
expect_error(ValueError, lambda: posterior(0, 1, 0))
```

**Why it works:** Rare events can yield many false alarms even with high sensitivity.

## 02c-E3: Bootstrap mean interval

**Question:** Return the 2.5th and 97.5th percentile order statistics of 1000 bootstrap means using seed=42. Require nonempty data.

**Answer:**

```python
def bootstrap_ci(xs, repeats=1000, seed=42):
    import random
    if not xs or repeats < 40: raise ValueError("Insufficient data or repeats")
    rng = random.Random(seed)
    means = sorted(sum(rng.choices(xs, k=len(xs)))/len(xs) for _ in range(repeats))
    return means[int(.025*repeats)], means[int(.975*repeats)]
```

**Checks:**

```python
lo, hi = bootstrap_ci([1, 2, 3, 4, 5])
assert lo <= 3 <= hi
assert bootstrap_ci([2]*10) == (2, 2)
```

**Why it works:** This simple percentile interval assumes representative independent observations; time series need block-aware methods.

**Test your own work:** [Interface, starter, and acceptance tests](../assignments/02c.md)

**Worked answer:** The script draws 10,000 Bernoulli(.3) outcomes, 10,000 Binomial(20,.3) counts, and 10,000 standard-normal samples using seed 42. It saves a binomial histogram, normal percentiles, a bootstrap mean interval, and a permutation p-value. covariance([1,2,3],[2,4,6])=2 and correlation=1; constant inputs have undefined correlation. The permutation test uses absolute mean differences and the (extreme+1)/(repeats+1) convention. IID resampling measures sampling variation under its assumptions; it cannot fix a biased sample. Trying many hypotheses and reporting only the smallest p-value inflates false positives; predeclare comparisons or use a justified multiple-testing adjustment.
