## 01d-E1: Inventory object

**Question:** Implement Inventory with fresh per-instance items and add(name, quantity); quantity must be positive.

**Answer:**

```python
class Inventory:
    def __init__(self):
        self.items = {}
    def add(self, name, quantity):
        if quantity <= 0: raise ValueError("Positive quantity required")
        self.items[name] = self.items.get(name, 0) + quantity
```

**Checks:**

```python
a, b = Inventory(), Inventory()
a.add("book", 2)
assert a.items == {"book": 2} and b.items == {}
expect_error(ValueError, lambda: a.add("book", 0))
```

**Why it works:** A shared class dictionary would contaminate every inventory.

## 01d-E2: Binary search

**Question:** For sorted ascending values, return an index of target, else -1. Use an iterative halving algorithm.

**Answer:**

```python
def binary_search(values, target):
    lo, hi = 0, len(values) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if values[mid] == target: return mid
        if values[mid] < target: lo = mid + 1
        else: hi = mid - 1
    return -1
```

**Checks:**

```python
assert binary_search([1, 3, 5, 7], 5) == 2
assert binary_search([], 1) == -1
assert binary_search([1, 3], 2) == -1
```

**Why it works:** Each comparison halves the remaining search space. Sorting first costs more than one linear lookup.

## 01d-E3: Regression fix

**Question:** Return the arithmetic mean of values. Empty input raises ValueError; do not divide by len(values)-1.

**Answer:**

```python
def average(values):
    if not values: raise ValueError("Empty sample")
    return sum(values) / len(values)
```

**Checks:**

```python
assert average([2, 4]) == 3
assert average([9]) == 9
expect_error(ValueError, lambda: average([]))
```

**Why it works:** The denominator n-1 belongs to sample variance, not the mean.
