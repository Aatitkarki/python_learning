## 14b-E1: Past-only feature

**Question:** Return a Series containing the mean of the previous window prices, excluding today; incomplete windows stay NaN.

**Answer:**

```python
def lagged_mean(prices, window=2):
    return prices.shift(1).rolling(window).mean()
```

**Checks:**

```python
values = lagged_mean(pd.Series([10, 20, 100, 200]))
assert values.iloc[2] == 15 and values.iloc[3] == 60
```

**Why it works:** An unshifted close-price feature may be unavailable when the decision must be made.

## 14b-E2: Chronological split

**Question:** Return train indices [0,cut-gap) and test [cut,n); require 0<=gap<cut<n.

**Answer:**

```python
def temporal_split(n, cut, gap=0):
    if not 0 <= gap < cut < n: raise ValueError("Invalid split")
    return list(range(cut-gap)), list(range(cut,n))
```

**Checks:**

```python
assert temporal_split(10, 6, 2) == ([0, 1, 2, 3], [6, 7, 8, 9])
```

**Why it works:** Choose gap from label overlap and information timing, not a fixed magic number.

## 14b-E3: Net strategy return

**Question:** Given period returns and positions decided before each period, subtract fee*absolute position change from each gross return; initial position is zero.

**Answer:**

```python
def net_returns(returns, positions, fee=.001):
    if len(returns) != len(positions): raise ValueError("Length mismatch")
    previous, result = 0, []
    for ret, position in zip(returns, positions):
        result.append(position*ret-fee*abs(position-previous))
        previous = position
    return result
```

**Checks:**

```python
assert abs(net_returns([.1, .1], [1, 0])[0]-.099) < 1e-12
assert net_returns([.1, .1], [1, 0])[1] == -.001
```

**Why it works:** This simple proportional-cost model omits spread, slippage, market impact, and financing.
