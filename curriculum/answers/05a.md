## 05a-E1: Stable sigmoid

**Question:** Return a sigmoid for NumPy input without overflowing exp on large magnitudes.

**Answer:**

```python
def sigmoid(x):
    import numpy as np
    x = np.asarray(x, dtype=float)
    z = np.exp(-np.abs(x))
    return np.where(x >= 0, 1/(1+z), z/(1+z))
```

**Checks:**

```python
assert np.allclose(sigmoid([-1000, 0, 1000]), [0, .5, 1])
```

**Why it works:** Numerical stability is part of correctness, not a cosmetic optimization.

## 05a-E2: Linear backward pass

**Question:** For X(n,d), y(n,1), w(d,1), scalar b, return MSE, dw, db.

**Answer:**

```python
def backward(x, y, w, b):
    residual = x @ w + b - y
    loss = float((residual**2).mean())
    return loss, 2*x.T@residual/len(x), float(2*residual.mean())
```

**Checks:**

```python
x = np.array([[1.], [2.]])
y = 2*x
w = np.zeros((1, 1))
loss, dw, db = backward(x, y, w, 0)
assert loss == 10 and np.allclose(dw, [[-10]]) and db == -6
```

**Why it works:** Batch averaging must be applied consistently to loss and gradients.

## 05a-E3: Training loop

**Question:** Use backward to fit w,b from zeros with 500 updates and lr=.05. Return w,b,loss history.

**Answer:**

```python
def train_linear(x, y, steps=500, lr=.05):
    import numpy as np
    w, b, history = np.zeros((x.shape[1], 1)), 0., []
    for _ in range(steps):
        loss, dw, db = backward(x, y, w, b)
        history.append(loss)
        w -= lr*dw
        b -= lr*db
    return w, b, history
```

**Checks:**

```python
w, b, history = train_linear(np.array([[-1.], [0.], [1.]]), np.array([[-1.], [1.], [3.]]))
assert history[-1] < 1e-8 and np.allclose(w, [[2]], atol=1e-3)
```

**Why it works:** Mixing updated and old parameters within one backward pass produces incorrect gradients.
