## 01a-E1: Profit function

**Question:** Return (sell-buy)*shares. Require shares > 0 and prices >= 0.

**Answer:**

```python
def profit(buy, sell, shares):
    if shares <= 0 or min(buy, sell) < 0:
        raise ValueError("Invalid price or quantity")
    return (sell - buy) * shares
```

**Checks:**

```python
assert profit(100, 110, 10) == 100
assert profit(10, 8, 2) == -4
expect_error(ValueError, lambda: profit(1, 2, 0))
```

**Why it works:** Separate invalid inputs from valid but undesirable business outcomes.

## 01a-E2: Calculator

**Question:** Support +, -, *, /. Reject unknown operators with ValueError and division by zero with ZeroDivisionError.

**Answer:**

```python
def calculate(a, op, b):
    if op == "+": return a + b
    if op == "-": return a - b
    if op == "*": return a * b
    if op == "/": return a / b
    raise ValueError("Unknown operator")
```

**Checks:**

```python
assert calculate(6, "/", 2) == 3
assert calculate(6, "-", 9) == -3
expect_error(ZeroDivisionError, lambda: calculate(2, "/", 0))
expect_error(ValueError, lambda: calculate(2, "**", 4))
```

**Why it works:** An allowlist keeps the behavior small, readable, and testable.

## 01a-E3: Tiered shipping

**Question:** Orders >= 100 ship free; smaller nonnegative orders cost 5. A negative total raises ValueError.

**Answer:**

```python
def shipping(total):
    if total < 0: raise ValueError("Negative total")
    return 0 if total >= 100 else 5
```

**Checks:**

```python
assert [shipping(x) for x in (0, 99, 100)] == [5, 5, 0]
expect_error(ValueError, lambda: shipping(-1))
```

**Why it works:** Boundary examples find off-by-one and incorrect comparison operators.
