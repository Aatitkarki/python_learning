## 02a-E1: Dot product

**Question:** Return sum(a_i*b_i); reject unequal lengths.

**Answer:**

```python
def dot(a, b):
    if len(a) != len(b): raise ValueError("Shape mismatch")
    return sum(x*y for x, y in zip(a, b))
```

**Checks:**

```python
assert dot([1, 2], [3, 4]) == 11
expect_error(ValueError, lambda: dot([1], [2, 3]))
```

**Why it works:** A dimension error must be visible rather than becoming a plausible wrong result.

## 02a-E2: Cosine similarity

**Question:** Use dot to return cosine similarity; reject a zero vector.

**Answer:**

```python
def cosine(a, b):
    import math
    numerator = dot(a, b)
    denominator = math.sqrt(dot(a, a) * dot(b, b))
    if denominator == 0: raise ValueError("Zero vector")
    return numerator / denominator
```

**Checks:**

```python
assert abs(cosine([1, 0], [0, 1])) < 1e-12
assert abs(cosine([2, 2], [1, 1])-1) < 1e-12
expect_error(ValueError, lambda: cosine([0, 0], [1, 2]))
```

**Why it works:** Two differently scaled embeddings can have the same direction.

## 02a-E3: Matrix multiplication

**Question:** Multiply nonempty rectangular nested lists. Validate rectangularity and inner dimensions.

**Answer:**

```python
def matmul(a, b):
    if not a or not b or not a[0] or not b[0]: raise ValueError("Empty matrix")
    if any(len(row) != len(a[0]) for row in a) or any(len(row) != len(b[0]) for row in b):
        raise ValueError("Ragged matrix")
    if len(a[0]) != len(b): raise ValueError("Shape mismatch")
    return [[dot(row, col) for col in zip(*b)] for row in a]
```

**Checks:**

```python
assert matmul([[1, 2]], [[3], [4]]) == [[11]]
assert matmul([[2, 3]], [[1, 0], [0, 1]]) == [[2, 3]]
expect_error(ValueError, lambda: matmul([[1, 2]], [[1, 2]]))
```

**Why it works:** Matrix multiplication is not elementwise multiplication; shape reasoning catches many neural-network bugs.
