## 13a-E1: Recall at k

**Question:** Use unique IDs in top k; return relevant-hit count / number of relevant IDs. An empty relevance set raises ValueError.

**Answer:**

```python
def recall_at_k(retrieved, relevant, k):
    relevant = set(relevant)
    if not relevant or k < 1: raise ValueError("Invalid evaluation case")
    return len(set(retrieved[:k]) & relevant)/len(relevant)
```

**Checks:**

```python
assert recall_at_k(["a", "a", "b"], {"a", "b"}, 2) == .5
assert recall_at_k([], {"a"}, 3) == 0
```

**Why it works:** Use a separate abstention metric for questions with no relevant evidence.

## 13a-E2: Reciprocal rank

**Question:** Return reciprocal rank of first relevant ID, else 0.

**Answer:**

```python
def reciprocal_rank(retrieved, relevant):
    return next((1/rank for rank, id in enumerate(retrieved, 1) if id in relevant), 0.)
```

**Checks:**

```python
assert reciprocal_rank(["x", "a"], {"a"}) == .5
assert reciprocal_rank(["x"], {"a"}) == 0
```

**Why it works:** MRR rewards finding one useful result early and does not measure complete coverage.

<a id="13a-e3"></a>
## 13a-E3: Citation precision

**Question:** Given one boolean human support judgment per citation, return supported/total; no citations returns None.

**Answer:**

```python
def citation_precision(supports):
    return sum(supports)/len(supports) if supports else None
```

**Checks:**

```python
assert citation_precision([True, False, True]) == 2/3
assert citation_precision([]) is None
```

**Why it works:** A system returning no citations should not receive a perfect citation-support score by convention.
