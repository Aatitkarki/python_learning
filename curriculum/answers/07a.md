## 07a-E1: Overlapping chunks

**Question:** Return word chunks with size>0 and 0<=overlap<size. Avoid an extra final chunk made only of overlap.

**Answer:**

```python
def chunks(text, size=4, overlap=1):
    if size <= 0 or not 0 <= overlap < size: raise ValueError("Invalid chunk configuration")
    words, result = text.split(), []
    start = 0
    while start < len(words):
        result.append(" ".join(words[start:start+size]))
        if start+size >= len(words): break
        start += size-overlap
    return result
```

**Checks:**

```python
assert chunks("a b c d e f", 4, 1) == ["a b c d", "d e f"]
assert chunks("") == []
expect_error(ValueError, lambda: chunks("a", 2, 2))
```

**Why it works:** Poor stopping conditions create redundant tail chunks that skew ranking.

## 07a-E2: Lexical retrieval

**Question:** For dicts with id,text, rank documents by number of shared unique lowercase alphanumeric terms; omit zero scores, break ties by id.

**Answer:**

```python
def retrieve(query, documents, k=3):
    import re
    terms = lambda s: set(re.findall(r"[a-z0-9]+", s.lower()))
    q = terms(query)
    scored = [(len(q & terms(d["text"])), d["id"]) for d in documents]
    return [id for score, id in sorted(scored, key=lambda pair: (-pair[0], pair[1])) if score > 0][:k]
```

**Checks:**

```python
docs = [{"id": "a", "text": "Revenue margin"}, {"id": "b", "text": "Password reset"}]
assert retrieve("revenue", docs) == ["a"]
assert retrieve("unicorn", docs) == []
```

**Why it works:** This is an inspectable baseline, not semantic retrieval or BM25.

## 07a-E3: Reciprocal rank fusion

**Question:** Combine ranked ID lists using sum(1/(c+rank)), rank starting at 1. Count an ID at most once per list; tie-break by ID.

**Answer:**

```python
def rrf(rankings, c=60):
    scores = {}
    for ranking in rankings:
        seen = set()
        for rank, id in enumerate(ranking, 1):
            if id not in seen:
                scores[id] = scores.get(id, 0)+1/(c+rank)
                seen.add(id)
    return sorted(scores, key=lambda id: (-scores[id], id))
```

**Checks:**

```python
assert rrf([["a", "b"], ["b", "c"]])[0] == "b"
```

**Why it works:** Raw cosine and keyword scores are not directly comparable without calibration.
