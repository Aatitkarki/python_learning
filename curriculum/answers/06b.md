## 06b-E1: Shifted examples

**Question:** Return sequence[:-1] and sequence[1:] for a 1D tensor of at least two tokens.

**Answer:**

```python
def shifted(sequence):
    if sequence.ndim != 1 or len(sequence) < 2: raise ValueError("Need a token sequence")
    return sequence[:-1], sequence[1:]
```

**Checks:**

```python
x, y = shifted(torch.tensor([3, 1, 4]))
assert x.tolist() == [3, 1] and y.tolist() == [1, 4]
```

**Why it works:** Correct alignment prevents the identity-copying shortcut.

## 06b-E2: Future mask

**Question:** Return an n×n boolean mask where True blocks future keys; diagonal stays False.

**Answer:**

```python
def causal_mask(n):
    return torch.triu(torch.ones(n, n, dtype=torch.bool), diagonal=1)
```

**Checks:**

```python
mask = causal_mask(3)
assert mask.tolist() == [[False, True, True], [False, False, True], [False, False, False]]
```

**Why it works:** Check your library’s mask convention rather than assuming True always means keep.

## 06b-E3: Transformer block

**Question:** Implement TinyBlock with batch_first MultiheadAttention(d,2), LayerNorm, and residual connection. Forward accepts (N,T,d), uses causal_mask, returns same shape.

**Answer:**

```python
class TinyBlock(nn.Module):
    def __init__(self, d=8):
        super().__init__()
        self.attn = nn.MultiheadAttention(d, 2, batch_first=True)
        self.norm = nn.LayerNorm(d)
    def forward(self, x):
        out, _ = self.attn(x, x, x, attn_mask=causal_mask(x.shape[1]).to(x.device), need_weights=False)
        return self.norm(x+out)
```

**Checks:**

```python
block = TinyBlock().eval()
x = torch.randn(1, 4, 8)
changed = x.clone(); changed[:, 3] += 10
assert block(x).shape == x.shape
assert torch.allclose(block(x)[:, :3], block(changed)[:, :3], atol=1e-6)
```

**Why it works:** A future-token perturbation is a meaningful causal-mask test, beyond just checking shape.

## 06b-T: Independent assignment

**Question:** Train projects/stage06/tiny_lm.py, add a second block, compare held-out loss and generation, then implement cached inference as an extension. Explain why train loss alone is insufficient.

**Test your own work:** [Interface, starter, and acceptance tests](../assignments/06b.md)

**Worked answer:** CachedLM contains an explicit Q/K/V attention implementation with one or two residual/normalization/feed-forward blocks. Training compares those depths under the same seeded minibatch stream and reports held-out loss plus generated text. Each layer's cache stores past K/V tensors; the new query attends to cached past and current keys, and positional indices continue from the cached length. cache_agreement compares full-sequence and token-by-token cached logits rather than comparing only shapes. Context overflow is an error instead of silently reusing invalid positions. The repeated corpus is a mechanics exercise, so even falling validation loss does not establish general language competence.
