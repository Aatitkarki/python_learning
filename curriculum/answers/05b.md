## 05b-E1: Gradient with autograd

**Question:** Return derivative of sum(x²) as a tensor; create a fresh float tensor with gradients enabled.

**Answer:**

```python
def squared_gradient(values):
    x = torch.tensor(values, dtype=torch.float32, requires_grad=True)
    (x*x).sum().backward()
    return x.grad
```

**Checks:**

```python
assert torch.allclose(squared_gradient([1, -2]), torch.tensor([2., -4.]))
```

**Why it works:** Autograd reproduces the analytical gradient while handling larger computation graphs.

## 05b-E2: CNN shape

**Question:** Return a network mapping (N,1,8,8) to (N,10): Conv2d(1,4,3,padding=1), ReLU, Flatten, Linear(256,10).

**Answer:**

```python
def make_cnn():
    return nn.Sequential(nn.Conv2d(1, 4, 3, padding=1), nn.ReLU(), nn.Flatten(), nn.Linear(4*8*8, 10))
```

**Checks:**

```python
assert make_cnn()(torch.zeros(2, 1, 8, 8)).shape == (2, 10)
```

**Why it works:** Return logits: CrossEntropyLoss already performs a stable log-softmax internally.

## 05b-E3: One update

**Question:** Set training mode, zero gradients, compute cross entropy, backpropagate, step optimizer; return float loss.

**Answer:**

```python
def train_step(model, optimizer, x, y):
    model.train()
    optimizer.zero_grad()
    loss = nn.functional.cross_entropy(model(x), y)
    loss.backward()
    optimizer.step()
    return loss.item()
```

**Checks:**

```python
model = make_cnn()
optimizer = torch.optim.AdamW(model.parameters(), lr=.01)
x, y = torch.randn(4, 1, 8, 8), torch.tensor([0, 1, 2, 3])
before = model[-1].weight.detach().clone()
assert train_step(model, optimizer, x, y) > 0
assert not torch.equal(before, model[-1].weight)
```

**Why it works:** A parameter-change check catches an omitted optimizer step; a learning curve is still needed to establish useful training.
