## 09a-E1: Weight estimate

**Question:** Return GiB for parameters and bits; require positive values.

**Answer:**

```python
def weight_gib(parameters, bits):
    if parameters <= 0 or bits <= 0: raise ValueError("Positive sizes required")
    return parameters*bits/8/1024**3
```

**Checks:**

```python
assert weight_gib(1024**3, 8) == 1
assert weight_gib(1024**3, 4) == .5
```

**Why it works:** Always label decimal GB versus binary GiB to avoid unit errors.

## 09a-E2: KV estimate

**Question:** Return bytes for layers, kv_heads, head_dim, tokens, batch=1, bytes_per_value=2.

**Answer:**

```python
def kv_bytes(layers, kv_heads, head_dim, tokens, batch=1, bytes_per_value=2):
    return 2*layers*kv_heads*head_dim*tokens*batch*bytes_per_value
```

**Checks:**

```python
assert kv_bytes(2, 4, 8, 16) == 4096
```

**Why it works:** This simplified estimate omits block allocation and implementation overhead.

## 09a-E3: Nearest-rank percentile

**Question:** Return nearest-rank percentile p in (0,1] of nonempty values.

**Answer:**

```python
def percentile(values, p):
    import math
    if not values or not 0 < p <= 1: raise ValueError("Invalid percentile")
    return sorted(values)[math.ceil(p*len(values))-1]
```

**Checks:**

```python
assert percentile(list(range(1, 101)), .95) == 95
assert percentile([3], .5) == 3
```

**Why it works:** Percentile conventions differ; document yours and collect enough observations for tail estimates.
