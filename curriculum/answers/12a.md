## 12a-E1: Threat record

**Question:** Return a dictionary with asset,entry,impact,control; reject empty fields.

**Answer:**

```python
def threat(asset, entry, impact, control):
    result = dict(asset=asset, entry=entry, impact=impact, control=control)
    if any(not value.strip() for value in result.values()): raise ValueError("Incomplete threat")
    return result
```

**Checks:**

```python
assert threat("private docs", "retrieved text", "disclosure", "server ACL")["control"] == "server ACL"
```

**Why it works:** A testable control is stronger than an aspiration such as “be secure.”

## 12a-E2: HTML output handling

**Question:** Escape model text for display in an HTML text node, including quotes.

**Answer:**

```python
def safe_html(text):
    import html
    return html.escape(text, quote=True)
```

**Checks:**

```python
assert safe_html('<script>alert("x")</script>') == '&lt;script&gt;alert(&quot;x&quot;)&lt;/script&gt;'
```

**Why it works:** Escaping is context-specific: HTML text, URL attributes, JavaScript, and SQL require different controls.

## 12a-E3: Resource admission

**Question:** Allow only when chars<=4000, requested_tokens<=512, pending<10; require all inputs nonnegative.

**Answer:**

```python
def admit(chars, requested_tokens, pending):
    return min(chars, requested_tokens, pending) >= 0 and chars <= 4000 and requested_tokens <= 512 and pending < 10
```

**Checks:**

```python
assert admit(100, 128, 2)
assert not admit(100, 10000, 2)
assert not admit(100, 128, 10)
```

**Why it works:** Admission limits reduce unbounded consumption but still require runtime deadlines and tenant quotas.
