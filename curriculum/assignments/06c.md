## Public interface

extract_revenue(text) supports exactly one statement of the form COMPANY revenue was $NUMBER million/billion under the fictional USD convention. Supported results include status=supported, company, revenue as exact decimal text, currency, quote, start/end offsets. Other/ambiguous statements return status=unknown. offline_smoke() performs an actual tiny random-model adapter backward/update step and reports finite loss/trainable_parameters; it is explicitly not a pretrained benchmark.

```python
extract_revenue(text)
offline_smoke()
```

The starter shows callable signatures, including class methods. Implement the behavior in your own file. The tests provide concrete input/output examples; implementation details can differ from the reference.
