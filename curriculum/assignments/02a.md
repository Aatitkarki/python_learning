## Public interface

Use Python lists for vectors and nested lists for matrices. add/dot require equal vector lengths. transpose requires a nonempty rectangular matrix; matmul requires matching inner dimensions. norm/distance/cosine return scalars; zero-vector cosine raises ValueError. rotate takes a two-entry vector and a counterclockwise angle in radians. Outputs are checked with floating-point tolerance where needed.

```python
add(a, b)
dot(a, b)
transpose(matrix)
matmul(a, b)
norm(v)
distance(a, b)
cosine(a, b)
rotate(v, angle)
```

The starter shows callable signatures, including class methods. Implement the behavior in your own file. The tests provide concrete input/output examples; implementation details can differ from the reference.
