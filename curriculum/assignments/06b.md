## Public interface

CachedLM(vocab,blocks=2,width=24,context=128) is a torch.nn.Module. forward(ids,cache=None) returns (logits, updated_cache). IDs have shape batch/length. Cache is one (K,V) tensor pair per layer with shape batch/heads/length/head_dim. Preserve absolute position offsets when extending it; reject context overflow. Full and cached eval-mode logits must agree. Implement your own block internals; tests do not require a particular parameter naming scheme.
