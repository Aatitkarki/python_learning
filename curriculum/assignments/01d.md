## Public interface

factorial(n) accepts only nonnegative integers. directory_bytes(path) recursively counts regular-file bytes and excludes symlinks. compare_search(n,repetitions) returns n, repetitions, linear_seconds, binary_seconds, and an assumption statement about sorting. ExpenseAnalyzer(repository).report() calls repository.read() and returns the expense summary contract from 01c. main(argv) is the CLI boundary and returns a nonzero exit code for expected file failures. Reuse your previous modules via imports; you need not put their implementations in one file.

```python
factorial(n)
directory_bytes(path)
compare_search(n=10000, repetitions=100)
ExpenseAnalyzer (class; see starter methods)
main(argv=None)
```

The starter shows callable signatures, including class methods. Implement the behavior in your own file. The tests provide concrete input/output examples; implementation details can differ from the reference.
