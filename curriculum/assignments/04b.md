## Public interface

novel_tickets() returns at least 20 unique id/text/label/provenance records with access/billing/technical labels. ticket_errors() adds predicted, correct, review_category. clustering(output) runs blobs/moons with kmeans/dbscan and returns comparisons (dataset/model/ari_external_diagnostic plus other measurements), PCA results, and writes clusters.png. Synthetic labels may diagnose results but should not be secretly used for selection.

```python
novel_tickets()
ticket_errors()
clustering(output)
```

The starter shows callable signatures, including class methods. Implement the behavior in your own file. The tests provide concrete input/output examples; implementation details can differ from the reference.
