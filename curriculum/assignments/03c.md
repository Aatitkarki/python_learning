## Public interface

create_app(location,keys,seed=False,limit_per_minute=60) returns a FastAPI app with the Stage 03 route contracts. keys maps a credential of at least 24 characters to a tenant. GET /records requires auth; POST /records creates integer cents/category and returns 201. /summary and /statistics return count/total_cents. Responses carry X-Request-ID. ingest(store,tenant,path) uses the supplied course Store repository, validates the whole CSV before writing, and is idempotent for identical input.

```python
create_app(location=None, keys=None, seed=False, limit_per_minute=60)
ingest(store, tenant, path)
```
