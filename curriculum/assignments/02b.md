## Public interface

fit(xs,ys,steps=1000,lr=.02,penalty=0) returns (weight,bias,loss_history), initialized at zero. Each history entry is the objective BEFORE that update; update both parameters using their old values. objective(w,b,x,y,penalty) is mean squared error plus penalty*w*w. gradient_check returns the maximum absolute error between analytical and central-difference derivatives. A nonzero L2 penalty changes the optimum; a large rate is intentionally allowed so the divergence experiment is observable.

```python
fit(xs, ys, steps=1000, lr=0.02, penalty=0.0)
objective(w, b, x, y, penalty=0)
gradient_check(x, y, w=0.7, b=-0.2, penalty=0.1)
```
