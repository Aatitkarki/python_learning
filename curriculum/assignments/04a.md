## Public interface

regression() returns validation metrics by model (mean/linear/tree/forest/boosting), selected (minimum validation MAE), and final_test metrics. Each metric dictionary has mae/rmse/r2. classification() returns validation_macro_f1 for majority/logistic/forest/boosting, selected, test classification report, confusion_matrix, classes, and individual errors. Tests validate report consistency; review the split/fitting code separately to establish no leakage.

```python
regression()
classification()
```

The starter shows callable signatures, including class methods. Implement the behavior in your own file. The tests provide concrete input/output examples; implementation details can differ from the reference.
