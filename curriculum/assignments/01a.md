## Public interface

calculate(a, operator, b) returns a finite numeric result for + - * /. temperature(value, source, target) uses C/F units. profit(buy,sell,shares) returns (sell-buy)*shares; bmi(mass_kg,height_m) is arithmetic only. main(read=input, write=print) accepts commands calc A OP B, temp VALUE C F, profit BUY SELL SHARES, quit. Catch expected input errors, print a message containing error, and continue. Unexpected programmer errors propagate. The test suite includes five valid cases for each of the four arithmetic/conversion functions.

```python
calculate(a, operator, b)
temperature(value, source='C', target='F')
profit(buy, sell, shares)
bmi(mass_kg, height_m)
main(read=input, write=print)
```

The starter shows callable signatures, including class methods. Implement the behavior in your own file. The tests provide concrete input/output examples; implementation details can differ from the reference.
