## Public interface

Expose streaming_totals as in 11a and spark_comparison(rows,output). The latter runs real Spark at partitions 2/8/32, reconciles aggregates, compares salted totals, and performs a broadcast join. Return runs with partitions/seconds/total_cents, salted_totals_match, broadcast_join_rows; write plan-2.txt/plan-8.txt/plan-32.txt/broadcast-plan.txt. The Spark test is opt-in; an offline pass leaves it pending.

```python
streaming_totals(rows=1000000, batch_size=10000)
spark_comparison(rows, output)
```

The starter shows callable signatures, including class methods. Implement the behavior in your own file. The tests provide concrete input/output examples; implementation details can differ from the reference.
