## Public interface

run(output) actually exercises local HTTP failures and SQLite recovery, writes report.json and operations.html, and returns faults with case/status/expected/ok/seconds/request_id as applicable, simulated_model_timeout, sqlite_restore, passed, limits. Required cases include invalid_auth/malformed_body/oversized_prompt/missing_period/database_outage/corrupt_document. Tests inspect observed values, not just the passed flag. This local harness does not substitute for live service outages.

```python
run(output)
```

The starter shows callable signatures, including class methods. Implement the behavior in your own file. The tests provide concrete input/output examples; implementation details can differ from the reference.
