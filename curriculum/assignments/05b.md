## Public interface

digits_comparison(output,epochs=8) returns experiments, selected, test_report, errors, split_seed, model_card. Each experiment records name/architecture/best_validation_loss/epochs/parameters/seconds/history; history has training/validation loss per epoch. Save best_weights.pt and validation.png in the existing output directory. The automatic test uses one CPU epoch and checks mechanics, not a high accuracy threshold.

```python
digits_comparison(output, epochs=8)
```
