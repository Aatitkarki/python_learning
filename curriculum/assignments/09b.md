## Public interface

measure(operation,runs=30,concurrency=1) invokes a supplied callable returning text and optional tokens. Return observations (ok/seconds plus tokens/output_characters or error type), runs, concurrency, wall_seconds, failures, p50_seconds_all_attempts, p95_seconds_all_attempts, tokens_per_wall_second. Include failed attempts. Throughput is unknown (None) if successful token counts are unavailable. Reject nonpositive run/concurrency sizes.

```python
measure(operation, runs=30, concurrency=1)
```

The starter shows callable signatures, including class methods. Implement the behavior in your own file. The tests provide concrete input/output examples; implementation details can differ from the reference.
