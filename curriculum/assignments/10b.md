## Public interface

restore_copy(source,target) performs a real SQLite backup into a new path, verifies integrity, and returns (record_count,total_cents) for the records table. Reject an existing target with FileExistsError and preserve it byte-for-byte. This is the local recovery component; PostgreSQL, Compose, release, and deployment checks require their own evidence.

```python
restore_copy(source, target)
```
