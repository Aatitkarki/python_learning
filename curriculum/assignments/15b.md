## Public interface

growth(current,prior) is the sample unfamiliar feature from the defense guide. Input fields: company/year/revenue/currency/unit/source_id. Return status=answered, value as decimal fraction text, sources containing both prior/current IDs for comparable consecutive periods. Return status=unknown and value=None for missing prior, nonpositive base, or incompatible periods/units/company. Reject nonfinite amounts. The caller must authorize both records before invoking this arithmetic helper.

```python

```
