## Public interface

build() returns a LangGraph that interrupts for a proposal and resumes using approved/fingerprint. fingerprint(state) binds actor/proposal. ReviewStore(path) provides propose(run_id,actor,proposal,now=None,ttl=300) returning a fingerprint and resume(run_id,actor,fingerprint,approved,execute,now=None) returning status/result. Verify actor, exact fingerprint, expiry, and one-time status across reopened instances; unknown actor raises PermissionError and altered/expired/consumed proposals raise ValueError.

```python

fingerprint(state)
ReviewStore (class; see starter methods)
```
