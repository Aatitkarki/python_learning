## Public interface

complete_ratios(rows) accepts dictionaries using the bundled financial CSV schema and returns sorted company/year ratio rows with decimal-text or None values. Preserve source_id, prior_source_id, and publication metadata. Use only consecutive same-company/currency/unit prior periods; first-year growth and average-balance ROE/ROA are unknown. Reject duplicate periods, unbalanced statements, and nonpositive shares. The tests include expected numeric values and incompatible-history cases.
