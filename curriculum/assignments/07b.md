## Public interface

parse_document(path) extracts supported file text, excluding HTML script/style text. documents_from_paths(paths,tenant) returns id/text/source/tenant/public records; use content-versioned identities, public=False for uploaded files, and PDF page provenance. Empty extraction or unsupported formats raise ValueError. Offline tests cover Markdown/HTML/JSON; the PDF/model/vector-database integration remains explicit evidence.

```python
parse_document(path)
documents_from_paths(paths, tenant)
```

The starter shows callable signatures, including class methods. Implement the behavior in your own file. The tests provide concrete input/output examples; implementation details can differ from the reference.
