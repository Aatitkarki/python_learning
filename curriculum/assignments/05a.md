## Public interface

loss_grad(x,y,params) returns (scalar_MSE, gradients). params=[W1,b1,W2,b2]; use tanh hidden activations, linear scalar outputs, and a batch mean loss. Return gradients in parameter order with matching shapes. Do not mutate weights while calculating gradients. The tests independently perturb ten coordinates and train on four XOR examples; plotting and optimizer comparison remain project evidence.
