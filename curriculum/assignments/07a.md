## Public interface

chunks(document,size,overlap) accepts id/text/source/tenant/public fields and returns chunks with id/document_id/text/start/end/sha256/parser_version plus scope. start/end are exact character offsets. bm25(query,documents) returns one score per document. rankings(query,documents,tenant) returns keyword/vector/hybrid/reranked lists of authorized document dictionaries. The offline vector path can be TF-IDF if explicitly labeled; learned embedding comparisons remain a separate experiment.

```python
chunks(document, size=40, overlap=8)
bm25(query, documents, k1=1.5, b=0.75)
rankings(query, documents, tenant, embedder=None, reranker=None, k=3)
```

The starter shows callable signatures, including class methods. Implement the behavior in your own file. The tests provide concrete input/output examples; implementation details can differ from the reference.
