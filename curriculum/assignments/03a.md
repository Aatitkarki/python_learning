## Public interface

clean(frame) returns (valid_dataframe, quarantine_dataframe, rolling_series, report_dict), without changing the input frame. Input columns: date/category/amount. Quarantine adds source_row (header means first row is line 2) and reason including invalid_date, invalid_amount, blank_category, or exact_duplicate. Complete calendar gaps with zero recorded spending before a trailing three-day mean. Report input_rows/valid_rows/quarantined_rows and the exclusion policy.

```python

```
