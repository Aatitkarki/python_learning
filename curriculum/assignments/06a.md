## Public interface

probabilities(logits,temperature=1,top_k=None,top_p=1) returns a normalized NumPy vector with stable softmax and filtering. Invalid sampling parameters raise ValueError. entropy(p) uses natural logs and zero contribution for zero probabilities. causal_attention(q,k,v) accepts 2D arrays and returns (outputs,weights), with no weight above the causal diagonal.

```python
probabilities(logits, temperature=1.0, top_k=None, top_p=1.0)
entropy(p)
causal_attention(q, k, v)
```
