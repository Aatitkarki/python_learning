## Public interface

load_expenses(path) returns records with date as datetime.date, category as text, and amount as Decimal. Header is date,category,amount. Bad rows raise ValueError containing the CSV line number. summarize(records) returns count, total, average, highest, by_category, by_month. Money is decimal text; month keys are YYYY-MM; mean/highest are None for no records. Use temporary paths supplied by the tests.

```python
load_expenses(path)
summarize(records)
```

The starter shows callable signatures, including class methods. Implement the behavior in your own file. The tests provide concrete input/output examples; implementation details can differ from the reference.
