## Public interface

ResearchWorkflow(store,tenant,max_calls=5,seconds=10) exposes execute(call) and run(calls). Calls have exactly tool/arguments. Allow search(query,k), financials(companies,years), divide(numerator,denominator). run returns status=complete/failed/budget_exhausted and observations with status/result/error. Reject caller tenant overrides, unknown tools, zero denominator, and nonfinite values. Trusted scope is supplied separately from arguments.
