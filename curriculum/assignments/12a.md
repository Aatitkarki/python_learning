## Public interface

fixtures() returns >=20 uniquely named HTTP method/path/key/expected-status inputs. threat_model() returns concrete asset/entry/impact/control/residual rows. run(output) executes the fixtures and returns checks, permission_matrix, limits. Matrix rows contain tenant/resource/expected/observed/passed, with both allowed and denied controls. Inspect actual report traces; report-shape checks cannot prove complete attack coverage.

```python
fixtures()
threat_model()
run(output)
```

The starter shows callable signatures, including class methods. Implement the behavior in your own file. The tests provide concrete input/output examples; implementation details can differ from the reference.
