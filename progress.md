1. What can I build independently now?
2. Which explanation or test exposed a gap?
3. Which mistakes recur?

## Evidence rules

Use links to code, notebook output, tests, reports, and recordings. Mark **passed** only after an independent attempt. Mark external-service/hardware work **pending** until run. Never award mastery because the reference implementation passed its tests.
